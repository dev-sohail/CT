# 📊 Route Logging System Documentation

## Overview

The CyberTirah Framework includes a comprehensive route logging system that automatically saves all registered routes to `storage/logs/all_routes.json`. This serves both as a detailed log for debugging and as a cache for quick reference.

---

## 🎯 Purpose

### Primary Uses

1. **Debugging** - See all registered routes at a glance
2. **Documentation** - Auto-generated route documentation
3. **Cache** - Quick lookup for available routes
4. **Statistics** - Route usage and distribution insights
5. **API Reference** - Easy reference for API development
6. **Monitoring** - Track route changes over time

---

## 📁 File Location

```
storage/logs/all_routes.json
```

This file is automatically generated and updated every time routes are loaded.

## 🔧 API Methods

### Enable Logging

```php
// Enable with default path (storage/logs/all_routes.json)
Router::enableLogging();

// Enable with custom path
Router::enableLogging('/custom/path/routes.json');
```

### Disable Logging

```php
Router::disableLogging();
```

### Log Routes Manually

```php
// Log if enabled
Router::logRoutes();

// Force log even if disabled
Router::logRoutes(true);
```

### Get Statistics

```php
$stats = Router::getRouteStatistics();

// Returns:
// [
//     'total_routes' => 16,
//     'by_method' => ['GET' => 13, 'POST' => 3],
//     'with_middleware' => 0,
//     'with_names' => 16,
//     'named_routes' => 16
// ]
```

### Clear Log

```php
Router::clearLog();
```

## 💻 Usage Examples

### Example 1: View All Routes in Controller

```php
<?php

class DevToolsController extends Controller
{
    public function routes(): void
    {
        // Read the log file
        $logPath = ROOT . '/storage/logs/all_routes.json';
        
        if (file_exists($logPath)) {
            $routeData = json_decode(file_get_contents($logPath), true);
            
            $data = [
                'title' => 'All Routes',
                'routes' => $routeData['routes'],
                'statistics' => $routeData['statistics'],
                'meta' => $routeData['meta']
            ];
            
            $this->load->view('dev/routes', $data);
        }
    }
}
```

### Example 2: API Endpoint for Routes

```php
<?php

class ApiController extends Controller
{
    public function getAllRoutes(): void
    {
        header('Content-Type: application/json');
        
        $logPath = ROOT . '/storage/logs/all_routes.json';
        
        if (file_exists($logPath)) {
            echo file_get_contents($logPath);
        } else {
            echo json_encode([
                'error' => 'Routes not logged yet'
            ]);
        }
    }
    
    public function getRouteStats(): void
    {
        header('Content-Type: application/json');
        
        $stats = Router::getRouteStatistics();
        echo json_encode($stats, JSON_PRETTY_PRINT);
    }
}
```

### Example 3: CLI Command to View Routes

```php
<?php
// cli/routes.php

require_once __DIR__ . '/../Brain/ct_brain.php';

$logPath = ROOT . '/storage/logs/all_routes.json';

if (!file_exists($logPath)) {
    echo "No routes logged yet. Visit the application to generate routes.\n";
    exit(1);
}

$data = json_decode(file_get_contents($logPath), true);

echo "\n";
echo "═══════════════════════════════════════════════════════\n";
echo "  CYBERTIRAH FRAMEWORK - ALL ROUTES\n";
echo "═══════════════════════════════════════════════════════\n";
echo "Generated: {$data['meta']['generated_at']}\n";
echo "Total Routes: {$data['meta']['total_routes']}\n";
echo "Environment: {$data['meta']['environment']}\n";
echo "═══════════════════════════════════════════════════════\n\n";

// Group by method
$byMethod = [];
foreach ($data['routes'] as $route) {
    $method = $route['method'];
    if (!isset($byMethod[$method])) {
        $byMethod[$method] = [];
    }
    $byMethod[$method][] = $route;
}

foreach ($byMethod as $method => $routes) {
    echo "\n{$method} Routes (" . count($routes) . "):\n";
    echo str_repeat('-', 60) . "\n";
    
    foreach ($routes as $route) {
        $name = $route['name'] ? " [{$route['name']}]" : '';
        echo "  {$route['path']}{$name}\n";
        echo "    → {$route['handler']}\n";
        
        if (!empty($route['middleware'])) {
            echo "    Middleware: " . implode(', ', $route['middleware']) . "\n";
        }
        
        echo "\n";
    }
}

echo "═══════════════════════════════════════════════════════\n\n";
```

Run: `php cli/routes.php`

## 📊 Log Contents

### Meta Information

- **framework**: Framework name
- **version**: Current version
- **generated_at**: Human-readable timestamp
- **timestamp**: Unix timestamp
- **total_routes**: Total number of routes
- **total_named_routes**: Routes with names
- **methods**: HTTP methods used
- **environment**: Current environment (dev/prod)

### Statistics

- **by_method**: Count of routes per HTTP method
- **with_middleware**: Routes that have middleware
- **with_names**: Routes with names
- **with_params**: Routes with dynamic parameters

### Named Routes

Quick lookup table of all named routes with their details.

### Routes Array

Complete list of all routes with:
- **method**: HTTP method (GET, POST, etc.)
- **path**: Route path pattern
- **handler**: Controller@method or Closure
- **name**: Route name (if any)
- **middleware**: Applied middleware (if any)
- **params**: Dynamic parameters (if any)

## 🔄 Automatic Generation

### When Routes Are Logged

Routes are automatically logged in the following situations:

1. **On Application Start** - When `Index/index.php` loads routes
2. **After Route Registration** - When all modules are scanned
3. **On Cache Save** - When route cache is generated

### Logging Trigger

```php
// In Index/index.php (lines 228-232)

// Log all routes to JSON (for both logging and caching)
if ($loadedRoutes > 0) {
    Router::enableLogging();
    Router::logRoutes();
}
```

## 🔒 Security Considerations

### File Permissions

```bash
# Set appropriate permissions
chmod 644 storage/logs/all_routes.json
```

### Production Use

In production, you may want to:
1. Restrict access to logs directory
2. Exclude from public access (.htaccess)
3. Clear logs periodically
4. Use environment-based logging

### .htaccess for Storage

```apache
# storage/logs/.htaccess
Order Deny,Allow
Deny from all
```

## 📝 Customization

### Custom Log Format

You can extend the Router to add custom data to the log:

```php
// In your bootstrap

class CustomRouter extends Router
{
    public static function logRoutesCustom(): bool
    {
        // Get standard log
        $logData = parent::logRoutes();
        
        // Add custom data
        $logData['custom'] = [
            'project' => 'My Project',
            'team' => 'Dev Team',
            'notes' => 'Additional info'
        ];
        
        // Save
        file_put_contents(self::$logFile, json_encode($logData, JSON_PRETTY_PRINT));
        
        return true;
    }
}
```
